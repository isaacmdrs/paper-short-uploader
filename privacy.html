Paper Short Uploader

Privacy Policy

Last updated 26 September 2026

Paper Short Uploader ("the tool") is a personal desktop tool used by the creator of the YouTube channel SOLTA SOLTA to upload his own videos to that channel. The tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. How Google handles your data is described in the Google Privacy Policy.

Information the tool accesses

When the creator signs in with Google, he grants the tool two permissions:

  • Manage your YouTube videos (youtube.upload): used only to upload the creator's own finished videos to his channel.
  • View your YouTube account (youtube.readonly): used only to read the connected channel's name, handle and ID, so the tool can show which channel is connected and refuse to upload to any other channel.

The tool does not access any other information from the Google account or from YouTube.

What is stored, and where

  • The sign-in token that Google issues to the tool, and the connected channel's name, handle and ID.
  • A small record of each upload: the video's ID, title and scheduled publish time.

All of this is kept only in a local folder on the creator's own computer. The tool has no server and no database, and it sends nothing anywhere except to Google's YouTube API when it uploads a video.

How the information is used and shared

The information is used only to upload the creator's videos to his own channel. It is not sold, not shared with anyone, and not used for analytics or advertising.

Cookies and device information

The tool does not place, access or recognize cookies, and it does not collect information from or about devices. This website is hosted on GitHub Pages; its author sets no cookies and uses no analytics. GitHub may process visit data as described in the GitHub Privacy Statement.

Keeping and deleting data

Stored data stays on the creator's computer until he deletes it. Access can be withdrawn at any time on the Google security settings page: security.google.com/settings/security/permissions. If access is withdrawn or the sign-in expires, the tool deletes its stored token and channel details the next time it runs. Deleting the tool's local folder removes everything at once.

Children

The tool is not directed at children and collects no information from them.
